# Prompt Logic & AI Agent Tool Chaining

Доклад на 45 минут на узбекском языке. Спикер — Shamsiddin, бренд — Shams.labs.

Презентация собрана в один HTML-файл. Внутри:
- 3D-слой: частицы, «нить» маршрута через все слайды, агент в 3D;
- кинетическая типографика и переходы между актами;
- анимированная сборка AI-агента;
- живые лаборатории на Claude.

## Как выступать

Есть два способа запуска.

1. **Файл `release/Prompt-Logic-Shams-labs.html`.**
   - Надёжный вариант, работает даже без сети.
   - Живые лаборатории работают, если ввести ключ Anthropic API в настройках (клавиша `,`).
   - Без ключа демо-агент проигрывает заранее записанный прогон.
   - В режиме с ключом используется модель `claude-opus-5-5`, сменить её можно в `CONFIG.apiModel`. Если модель откажется отвечать, включается резервная модель на стороне сервера.
2. **Ссылка на артефакт в claude.ai.** Живые лаборатории работают через ваш аккаунт Claude, ключ не нужен. При первом запросе браузер попросит разрешение.

Перед выступлением:
- Нажмите `F`, чтобы включить полный экран.
- Нажмите `P`, чтобы открыть окно спикера на втором экране. Там заметки, таймер и следующий слайд.
- Если проектор бледный, нажмите `T`, чтобы включить светлую тему.
- Если ноутбук слабый, нажмите `M`, чтобы включить облегчённую графику.

### Клавиши

| Клавиша | Действие |
|---|---|
| `→` `Space` `PgDn` | Следующий шаг |
| `←` `PgUp` | Предыдущий шаг |
| `Home` / `End` | В начало / в конец |
| `G` + номер + `Enter` | Перейти к слайду |
| `Esc` / `O` | Обзор всех слайдов |
| `F` | Полный экран |
| `P` | Окно спикера |
| `N` | Заметки на этом же экране |
| `L` | Лазерная указка |
| `S` | Прожектор (колесо мыши меняет размер) |
| `Z` | Увеличение (щёлкните по нужному месту) |
| `B` / `.` | Чёрный экран |
| `T` | Светлая тема для проектора |
| `M` | Облегчённая графика |
| `A` | Звуки интерфейса |
| `,` | Настройки: ключ API и ссылка для QR |
| `?` | Справка |

Кликер для презентаций тоже работает: он шлёт `PgUp`/`PgDn`.

## QR-код и репозитории

- **QR.** Пока ссылки нет, на слайдах «Bonus» и «Savollar?» показывается заглушка «tez orada». Ссылку можно задать двумя способами:
  - в самой презентации: клавиша `,` → поле «QR havola». Ссылка сохранится в этом браузере.
  - в исходниках: `presentation/src/config.js` → `qrUrl`, затем пересобрать.
- **Репозитории агентов.** Добавьте их в `CONFIG.repos` в `presentation/src/config.js` в виде `{ name, url, note }` и пересоберите. Пока список пуст, блок на бонус-слайде скрыт.

## Пересборка

```bash
cd presentation
npm install
npm run build                 # dist/index.html
node scripts/release.mjs      # release/*.html
npm run lint:uz               # проверка узбекских апострофов (ʻ ʼ)
node scripts/speaker-doc.mjs  # заново собрать speaker/nutq-matni.md из заметок
npm run video -- ../release/agent-assembly.mp4 60   # рендер видео (долго: ~1.5 ч на 4 ядрах)
```

Если рендер нужно разбить на части (например, из-за лимита времени задачи), отрисуйте части с `--from/--to --noaudio`, а затем склейте их со звуком:

```bash
node scripts/render-video.mjs ../release/part-a.mp4 60 --from=0 --to=35.98333 --noaudio
node scripts/render-video.mjs ../release/part-b.mp4 60 --from=36 --noaudio
node scripts/mux-video.mjs ../release/agent-assembly.mp4 ../release/part-a.mp4 ../release/part-b.mp4
```

Для разработки есть `npm run dev`.

Параметры адресной строки:
- `?lite` — облегчённая графика;
- `?nogl` — без 3D.
