# «Сначала — кофе.» — light motion demo (9:16)

20-second vertical (1080×1920, 30 fps) cartoon about the Monday-morning coffee: a sleepy glass mug wakes up while coffee is poured into it.
Every frame and every sound is generated by code: no stock, no samples.

- `renders/final/snachala_kofe_v1.mp4` — final (H.264 CRF 16, 6-subframe motion blur, AAC 256k, −14 LUFS)
- `renders/final/snachala_kofe_v1_web.mp4` — lighter copy for phones/messengers
- `plan/storyboard.md` — shot list with timings and sound map

## Rebuild
```bash
npm i
node scripts/preview.mjs 5 7.5                          # contact sheet → renders/previews/
node scripts/render.mjs --fps 30 --scale 1 --mb 6 --video renders/final/video_silent_v1.mp4
python3 scripts/audio.py                                 # → assets/music/mix_raw.wav
bash scripts/mux.sh                                      # loudnorm + mux → renders/final/snachala_kofe_v1.mp4
```
Stack: Canvas 2D in headless Chromium (Playwright) → ffmpeg. Fonts: Unbounded + Caveat (OFL). Audio: numpy synthesis (FM Rhodes, glock, xylophone, brush kit, resonant pour, etc.).
