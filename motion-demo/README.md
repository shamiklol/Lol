# «СДЕЛАНО КОДОМ» — motion demo

25-second 1080p/30fps motion piece where **every pixel and every sound is generated by code**: no camera, no stock, no samples.

- `renders/final/sdelano_kodom_v1.mp4` — final (H.264 CRF 16, AAC 256k, −14 LUFS)
- `renders/final/sdelano_kodom_v1_web.mp4` — lighter version for phones/messengers

Scenes: genesis dot → kinetic type → chrome 3D «КОД» in a warp tunnel → 40 000 particles (sphere → torus knot → galaxy → collapse) → 3D card wall → end card. See `plan/storyboard.md`.

## Rebuild
```bash
npm i
node scripts/preview.mjs 7 12            # contact sheet → renders/previews/
node scripts/render.mjs --fps 30 --scale 1 --video renders/final/video_silent_v1.mp4
python3 scripts/audio.py                 # synthesizes assets/music/mix_raw.wav (numpy)
bash scripts/mux.sh                      # loudnorm + mux → renders/final/sdelano_kodom_v1.mp4
```
Stack: Canvas 2D + Three.js (ExtrudeGeometry via opentype.js, MeshPhysicalMaterial, UnrealBloom), headless Chromium via Playwright, ffmpeg. Every frame is a pure function of `t`.
